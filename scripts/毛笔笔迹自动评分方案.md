# 毛笔笔迹自动评分方案

## 方案目标

使用固定俯视相机，在每个绘制任务开始和结束时各拍摄一张图片，自动判断机械臂画出的墨迹：

- 覆盖目标轮廓比率；

- 墨迹超出目标轮廓比率。

总体方案：

```Plain Text
标准模板图
+ ArUco 定位标记
+ 每个轮廓对应的标准 target mask
+ before/after 图像差分
+ 覆盖率和超出率评分
```

---

## 标准模板图

纸张模板由程序统一生成并打印，模板中包含：

- 多个横线、竖线等目标轮廓；

- 四个 ArUco 定位标记；

- 每个目标轮廓的编号。

模板图和所有 target mask 必须使用相同的图像尺寸和坐标系。

例如：

```Plain Text
纸张模板尺寸：2480 × 3508 像素
打印尺寸：A4，300 DPI
```

模板可以使用其他尺寸，但打印时不能进行不一致的拉伸或裁剪。

---

## 每个轮廓一个 target\_id

一张纸上有多个目标轮廓，每个轮廓必须分配唯一的 `target_id`。

例如：

```Plain Text
target_001：第一条竖线
target_002：第二条竖线
target_003：第三条竖线
target_004：第一条横线
target_005：第二条横线
```

每次绘制任务开始前，上层程序需要明确指定当前目标：

```Plain Text
current_target_id = target_003
```

评分程序只加载 `target_003` 对应的 target mask，不自动判断机械臂当前画的是哪个轮廓。

原因是纸张上可能已经存在其他墨迹，自动猜测目标容易出错。

---

## 标准 target mask

生成纸张模板时，需要同时为每个目标轮廓生成一张标准 target mask。

target mask 是一张二值图：

```Plain Text
目标轮廓内部：255，白色
其他区域：0，黑色
```

例如：

```Plain Text
target_001.png
target_002.png
target_003.png
```

注意，target mask 不是目标轮廓线，而是目标轮廓内部的完整填充区域。

生成模板时，同一个几何形状绘制两次：

```Plain Text
纸张模板：只画目标边界，供机械臂观察
target mask：填充目标内部，供程序评分
```

例如一个圆头竖线目标：

```Plain Text
模板图中：画圆头竖线的黑色或灰色轮廓
target mask 中：把圆头竖线内部全部填白
```

模板和 mask 使用完全相同的位置、宽度和长度参数，因此天然对齐。

---

## ArUco 视觉定位锚点设计

纸张可能被人移动或旋转，不能假设目标轮廓始终位于相机中的固定像素位置。

因此，在纸张四角打印四个 ArUco 标记，用于每次拍照时重新确定纸张的位置和方向。

推荐配置：

```Plain Text
ArUco 字典：DICT_4X4_50
左上角：ID 0
右上角：ID 1
右下角：ID 2
左下角：ID 3
```

布局示意：

```Plain Text
┌──────────────────────────────┐
│ [ID 0]                [ID 1] │
│                              │
│       多个目标轮廓区域        │
│                              │
│ [ID 3]                [ID 2] │
└──────────────────────────────┘
```

建议尺寸：

```Plain Text
ArUco 编码图案边长：30 mm
周围白色留边：5–10 mm
```

设计要求：

- 四个标记必须使用不同 ID；

- 标记不能被目标轮廓或墨迹覆盖；

- 标记不要紧贴纸张边缘；

- 标记周围应保留白色区域；

- 四个标记尽量靠近纸张四角，使配准更稳定；

- 夹子、机械臂和毛笔不能遮挡标记。

---

## 纸张动态配准

每次拍照后，程序使用 OpenCV 检测四个 ArUco 标记，得到它们在相机图像中的位置。

程序已经知道四个标记在标准模板图中的位置，因此可以计算从相机图像到标准模板坐标系的透视变换。

处理流程：

```Plain Text
相机拍摄图片
↓
检测 ID 0、1、2、3 的 ArUco
↓
获取四个标记的位置
↓
计算透视变换矩阵
↓
将相机图片变换到标准模板坐标系
```

建议将相机图片变换到标准模板坐标系，而不是把 target mask 变换到相机图片中。

最终得到：

```Plain Text
aligned_before
aligned_after
```

它们与标准 target mask 具有相同的尺寸和坐标系，可以直接进行比较。

如果四个 ArUco 没有全部检测到，可以尝试使用检测到的足够多角点计算配准；如果无法可靠配准，则本次评分应判定无效。

---

## Episode 图像采集

每个绘制任务拍摄两张图片：

```Plain Text
before：机械臂开始绘制前
after：机械臂完成绘制后
```

拍摄要求：

- before 和 after 使用相同分辨率；

- 一个 episode 内相机和纸张保持不动；

- 拍 after 前，机械臂和毛笔应离开目标区域；

- 图片中不要出现人的手；

- 四个 ArUco 标记应尽量完整可见。

纸张可以在不同 episode 之间移动，因为每次都会重新做 ArUco 配准。

---

## 提取当前 Episode 的墨迹

一张纸上可能已经画过很多条线，因此不能直接把 after 图中的所有黑色区域都当作当前墨迹。

需要使用 before/after 差分，只提取本次 episode 新增的墨迹。

处理流程：

```Plain Text
before 和 after 分别做 ArUco 配准
↓
转换到标准模板坐标系
↓
转为灰度图
↓
计算 before - after
↓
阈值分割
↓
得到新增墨迹 ink mask
```

墨水通常使图像变暗，因此可以使用：

```Plain Text
difference = gray_before - gray_after
```

差值大于阈值的区域视为新增墨迹。

随后做简单去噪：

- 去除面积很小的孤立噪点；

- 使用轻微闭运算填补墨迹内部的小空洞；

- 避免过强的形态学处理改变墨迹面积。

输出：

```Plain Text
ink mask：
新增墨迹区域 = 255
其他区域 = 0
```

评分时，只处理当前 `target_id` 周围的区域。

目标区域外应保留一定宽度，例如向外扩展 10–30 mm，以便统计超出的墨迹。

---

## 覆盖率

定义：

```Plain Text
T：当前 target_id 对应的目标 mask
I：当前 episode 新增墨迹的 ink mask
```

目标区域和墨迹的交集：

```Plain Text
intersection = I ∩ T
```

覆盖率表示目标区域被墨迹覆盖了多少：

```Plain Text
coverage = intersection_area / target_area
```

即：

```Plain Text
coverage = |I ∩ T| / |T|
```

示例：

```Plain Text
coverage = 1.0：目标区域全部覆盖
coverage = 0.8：覆盖了目标区域的 80%
coverage = 0.5：只覆盖了一半
```

覆盖不完整会直接降低分数。

---

## 超出部分

为了避免由于相机配准误差或轻微压线导致过度扣分，建议在标准 target mask 外增加一个小的容忍区域。

生成：

```Plain Text
T_tolerant = 对 T 向外膨胀 1–2 mm
```

真正算作超出的墨迹为：

```Plain Text
overflow_mask = I - T_tolerant
```

超出率可以定义为：

```Plain Text
overflow = overflow_area / ink_area
```

即：

```Plain Text
overflow = |I - T_tolerant| / |I|
```

含义：

```Plain Text
overflow = 0：墨迹没有明显超出
overflow = 0.1：10% 的墨迹位于目标区域外
overflow = 0.3：30% 的墨迹位于目标区域外
```

容忍区域的物理宽度建议从 1 mm 开始，根据实际配准误差调整。

---

## 总分

第一版只考虑覆盖率和超出率。

推荐公式：

```Plain Text
score = 100 × coverage - 60 × overflow
```

最后限制在 0–100 分：

```Plain Text
score = clip(score, 0, 100)
```

例如：

```Plain Text
coverage = 0.85
overflow = 0.10

score = 100 × 0.85 - 60 × 0.10
      = 79
```

权重可以根据实际效果调整。

如果认为出界比漏画更严重，可以提高超出惩罚：

```Plain Text
score = 100 × coverage - 80 × overflow
```

也可以采用乘法形式，使大量出界时得分下降更明显：

```Plain Text
score = 100 × coverage × (1 - overflow)
```

建议第一版同时输出：

```Plain Text
coverage
overflow
score
```

方便人工观察评分是否合理。

---

## 结果可视化

每次评分建议生成一张可视化图片：

```Plain Text
绿色：墨迹位于目标区域内的部分
红色：超出目标区域的墨迹
蓝色：目标区域中没有被覆盖的部分
```

这样可以快速判断：

- 哪里没有覆盖；

- 哪里画出了边界；

- 评分是否与肉眼判断一致。

可视化结果对于调节差分阈值、容忍区域宽度和评分权重非常重要。

---

## 异常情况

出现以下情况时，不应正常输出分数：

- before 或 after 图片缺失；

- ArUco 无法可靠检测；

- 图片严重模糊；

- 目标区域被手、机械臂或毛笔遮挡；

- before 图中当前目标已经存在大量墨迹；

- `target_id` 不存在；

- 对应 target mask 缺失；

- before 和 after 无法正确配准。

这些情况应标记为本次评分无效，避免生成错误奖励。

---

## 实施顺序

第一步只实现一个目标轮廓：

```Plain Text
生成模板和 target mask
↓
打印带四个 ArUco 的纸张
↓
拍摄 before/after
↓
完成图像配准
↓
提取 ink mask
↓
计算 coverage 和 overflow
↓
输出 score 和可视化图
```

确认单个目标评分可靠后，再增加：

```Plain Text
多个目标轮廓
多个 target_id
自动加载对应 target mask
```

最终系统应满足：

- 纸张移动或旋转后仍能正确评分；

- 能根据 target\_id 评价指定轮廓；

- 之前画过的其他墨迹不会影响当前评分；

- 覆盖不足时 coverage 降低；

- 出界增加时 overflow 升高；

- 可视化结果与人工观察基本一致。
